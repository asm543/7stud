포커 토너먼트

방을 만들고 링크를 보내면 친구가 바로 들어와요. 계정은 필요 없고, 빈자리는 컴퓨터가 채워요. 혼자 컴퓨터랑 해도 돼요.

새 방 게임 (로비에서도 바꿀 수 있어요)
또는 받은 코드로 참가

무료 서버는 한동안 아무도 없으면 잠들어서 첫 접속에 1분쯤 걸릴 수 있어요. 진행 중인 방은 서버가 재시작되면 사라져요.

대회 룰

  • 노리밋 텍사스 홀덤 토너먼트. 시작 스택 20,000, 레벨 1은 블라인드 100/200에 빅블라인드 앤티 200.
  • 빅블라인드 앤티(BBA): 빅블라인드가 테이블 전체 앤티를 냄. 칩이 모자라면 블라인드를 먼저 채우고 남는 칩으로 앤티. 앤티는 끝까지 줄이지 않음.
  • 버튼은 매 핸드 왼쪽으로. 탈락자가 생기면 데드 버튼 규칙: 빅블라인드는 항상 한 칸씩 이동.
  • 헤즈업: 버튼이 스몰블라인드. 프리플랍은 버튼이 먼저, 플랍부터는 빅블라인드가 먼저.
  • 최소 베트 = 빅블라인드. 레이즈는 직전 풀 베트·레이즈 크기 이상. 최대는 내 스택 전부(올인).
  • 풀 레이즈보다 적은 올인은 이미 액션한 사람에게 레이즈를 다시 열지 않음(콜·폴드만). 여러 숏 올인이 합쳐 풀 레이즈 이상이면 다시 열림.
  • 올인으로 더 이상 베팅이 없으면 남은 사람 카드를 공개하고 보드를 끝까지 깜. 콜 받지 못한 베트는 돌려줌.
  • 분할 팟의 남는 칩은 버튼 왼쪽에 가까운 승자에게. 폴드한 카드는 공개되지 않음.
  • 단축키: F 폴드 · C 체크/콜 · R 베트/레이즈 (금액은 슬라이더·버튼·직접 입력) · H 힌트 · Enter 다음 핸드 · / 채팅 입력
  • 매 핸드 전원 앤티. 3구는 히든 2장 + 오픈 1장.
  • 오픈 카드가 가장 낮은 사람이 브링인. 숫자가 같으면 ♣ < ♦ < ♥ < ♠ 중 낮은 무늬.
  • 브링인 다음 사람들은 fold / call / complete(스몰 단위까지).
  • 3·4구는 스몰, 5~7구는 빅 단위. 4구 오픈 페어 더블벳은 대회 룰대로 없음.
  • 레이즈 캡: 베트 1 + 레이즈 3 (팟 아래 점 4개). 4구부터는 보이는 패가 가장 높은 사람이 먼저, 같으면 낮은 좌석 번호.
  • 7구는 히든. 동점이면 분할하고, 무늬는 승패에 쓰지 않음.
  • 단축키: F 폴드 · C 체크/콜/브링인 · R 컴플리트/베트/레이즈 · H 힌트 · Enter 다음 핸드 · / 채팅 입력
